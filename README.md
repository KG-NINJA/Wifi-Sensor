# Presence Observer

ブラウザ内の実行環境で発生する微細なタイミング揺らぎやフェッチ遅延を抽象化し、オカルト風の観測儀として描写するシングルページ作品です。実際のセンサーや周囲の存在を検知するものではありません。

## セットアップ
GitHub Pages などで `wifisense/index.html` をそのままホストするだけで動作します。追加のライブラリやビルド処理は不要です。

## 操作
- 画面右下に表示される文言が観測状態を示します。
- 下部のスライダー「感度」で、タイミング揺らぎに対する反応量を調整できます。
  - 左(静)……鈍感、ほとんどの揺らぎを無視
  - 右(鋭)……敏感、小さな揺らぎでも反応

## 仕組み
- `requestAnimationFrame` の間隔と `performance.now()` を比較し、標準フレーム幅(約16.67ms)からの逸脱を「jitter」として蓄積。
- 数秒ごとに自身のドキュメントを `fetch` し、その往復遅延を「lag」として加算。
- `jitter` と `lag` を感度値でスケーリングし、しきい値を超えるとグラフィックが揺らぎ、さらに高い値ではサージ状態として輪郭や輝度が増幅されます。
